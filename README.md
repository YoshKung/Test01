# Test01

โปรเจกต์นี้เป็นตัวอย่างสำหรับเริ่มต้นโค้ด Python อย่างง่าย สามารถใช้เป็นฐานสำหรับโปรเจกต์ของคุณเองได้

## วิธีใช้งาน

1. โคลนรีโพสิโทรีนี้
   ```bash
   git clone <repository-url>
   ```
2. เข้าไปยังโฟลเดอร์โปรเจกต์
   ```bash
   cd Test01
   ```
3. (ถ้ามี) สร้าง virtual environment และติดตั้ง dependencies
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. สร้างไฟล์ `main.py` แล้วเขียนโค้ดของคุณ
5. รันโปรแกรม
   ```bash
   python main.py
   ```

สามารถปรับแต่งโปรเจกต์นี้เพิ่มเติมตามต้องการ
